# Ilhas de Conectividade

Projeto desenvolvido para a avaliação AV2 da disciplina de **Algoritmos de Alta Performance**.

## Problema

O problema consiste em identificar quantos pares de cidades estão desconectados entre si, considerando uma rede de cidades conectadas por estradas bidirecionais.

Duas cidades são consideradas conectadas quando existe um caminho entre elas, seja diretamente ou passando por outras cidades.

## Objetivo

Desenvolver um algoritmo eficiente capaz de identificar os componentes conexos de um grafo e calcular a quantidade de pares de cidades que pertencem a componentes diferentes.
